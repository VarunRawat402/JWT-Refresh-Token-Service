JWT + Refresh Token Service:
--------------------------------------------------------------------------------------------------------------------------------------------------

Signup():
→ For User Creation
→ Creates user
→ Returns JWT + refresh token

Input
→ UserInfoDto
  → username: String
  → password: String
  → name: String
  → age: String
  → designation: String

Flow
Step 1: Call `userService.signupUser(userInfoDto)`
Step 2: Check result
  → false: username already exists, return error
  → true: proceed
Step 3: Create refresh token
Step 4: Create JWT token
Step 5: Return JWT + refresh token

--------------------------------------------------------------------------------------------------------------------------------------------------

Login():
→ Used when refresh token and jwt token both expired
→ Authenticates user
→ Returns JWT + refresh token

Input
→ LoginDTO
  → username: String
  → password: String

Flow
Step 1: Call `AuthenticationManager.authenticate()` with username + password
Step 2: Check result
  → fail: Spring Security throws `AuthenticationException`
  → pass: proceed
Step 3: Create refresh token
Step 4: Create JWT token
Step 5: Return JWT + refresh token

--------------------------------------------------------------------------------------------------------------------------------------------------

RefreshToken():
→ Used when jwt token is expired
→ Validates refresh token
→ Returns new JWT token + old refresh token

Input
→ Refresh Token

Flow
Step 1: Fetch token using `refreshTokenService.findByToken()`
Step 2: Check result
  → not found: throw `RuntimeException`
  → found: proceed
Step 3: Verify expiry using `refreshTokenService.verifyExpiration()`
  → expired: service deletes token and throws exception
  → valid: proceed
Step 4: Read linked user from token entity
  → user is null: throw `RuntimeException`
Step 5: Create new JWT token
Step 6: Return new JWT token + old refresh token

POSTMAN HIT API DOCUMENTATION
--------------------------------------------------------------------------------------------------------------------------------------------------

1) SIGNUP API
Endpoint
→ POST /auth/v1/signup

What it takes
→ Content-Type: application/json
→ Body fields:
  → username (String)
  → password (String)
  → name (String)
  → age (String)
  → designation (String)

JSON format data to send
{
  "username": "varun",
  "password": "pass123",
  "name": "Varun",
  "age": "23",
  "designation": "Developer"
}

--------------------------------------------------------------------------------------------------------------------------------------------------

2) LOGIN API
Endpoint
→ POST /auth/v1/login

What it takes
→ Content-Type: application/json
→ Body fields:
  → username (String)
  → password (String)

JSON format data to send
{
  "username": "varun",
  "password": "pass123"
}

--------------------------------------------------------------------------------------------------------------------------------------------------

3) REFRESH TOKEN API
Endpoint
→ POST /auth/v1/refreshToken

What it takes
→ Content-Type: application/json
→ Body fields:
  → token (String, refresh token from signup/login response)

JSON format data to send
{
  "token": "paste_refresh_token_here"
}
