JWT + Refresh Token Service:
--------------------------------------------------------------------------------------------------------------------------------------------------

Signup():
→ Creates user
→ Returns JWT + refresh token

Input
→ UserInfoDto
  → username: String
  → password: String
  → name: String
  → age: String
  → designation: String

Flow
1: Call `userService.signupUser(userInfoDto)`
2: Check result
  → false: username already exists, return error
  → true: proceed
3: Create refresh token
4: Create JWT token
5: Return JWT + refresh token

--------------------------------------------------------------------------------------------------------------------------------------------------

Login():
→ Used when refresh token and jwt token both expired
→ Authenticates user
→ Returns JWT + refresh token

Input
→ LoginDTO
  → username: String
  → password: String

Flow
1: Call `AuthenticationManager.authenticate()` with username + password
2: Check result
  → fail: Spring Security throws `AuthenticationException`
  → pass: proceed
3: Create refresh token
4: Create JWT token
5: Return JWT + refresh token

--------------------------------------------------------------------------------------------------------------------------------------------------

RefreshToken():
→ Used when jwt token is expired
→ Validates refresh token
→ Returns new JWT token + old refresh token

Input
→ Refresh Token

Flow
1: Fetch token using `refreshTokenService.findByToken()`
2: Check result
  → not found: throw `RuntimeException`
  → found: proceed
3: Verify expiry using `refreshTokenService.verifyExpiration()`
  → expired: service deletes token and throws exception
  → valid: proceed
4: Read linked user from token entity
  → user is null: throw `RuntimeException`
5: Create new JWT token
6: Return new JWT token + old refresh token
